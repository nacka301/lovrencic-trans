# Lovrenčić Trans

Jednostranačna (one-page) web stranica za Lovrenčić Trans, obrt za prijevoz i selidbe iz Osijeka.

Statičan HTML/CSS/JS, bez build koraka — otvori `index.html` u pregledniku ili posluži preko GitHub Pages.

## Status: DEMO

Sadržaj obilježen `DEMO` oznakom (telefon, email, ocjena, brojke u sekciji "Zašto mi", radno vrijeme, popis gradova, Facebook poveznica) je placeholder i **mora se zamijeniti stvarnim podacima** prije slanja klijentu.
